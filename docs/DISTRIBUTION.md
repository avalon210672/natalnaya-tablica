# Как отдать программу пользователю «одним файлом»

**Как собрать на Mac/Windows:** [BUILD-LOCAL.md](./BUILD-LOCAL.md)

Есть два рабочих варианта — выбор зависит от того, нужен ли **установщик / .app** или достаточно **браузера**.

## Сравнение

| Вариант | Что получает пользователь | Нужен Rust при сборке | Диалоги файлов | Где хранятся рецепты |
|--------|---------------------------|------------------------|----------------|----------------------|
| **Portable HTML** | один `.html` (~2 МБ) + опционально скрипт запуска | нет | выбор файла в браузере | localStorage |
| **Tauri desktop** | `.app` (macOS) или `.exe` (Windows) | да | системные | папка AppData |

Оба варианта работают **офлайн**, данные Excel не уходят на сервер.

---

## 1. Portable — один HTML (рекомендуется, если нет Rust)

Сборка на машине разработчика:

```bash
npm install
npm run build:portable
```

Результат: папка `release/`:

- `Натальная-Таблица.html` — всё приложение в одном файле
- `Запуск (macOS).command` — двойной клик открывает HTML
- `Запуск (Windows).bat` — то же для Windows
- `КАК-ЗАПУСТИТЬ.txt` — инструкция для пользователя

**Что отдать:** zip-архив папки `release` или только `Натальная-Таблица.html`, если пользователь знает, что открыть его в Chrome/Edge.

**Запуск у пользователя:** двойной клик по `.command` / `.bat` или перетащить HTML в браузер. Node.js на компьютере пользователя **не нужен**.

---

## 2. Desktop — одно приложение (Tauri)

Требуется [Rust](https://rustup.rs) на машине, где собираете:

```bash
npm install
npm run build
```

Артефакты (пути могут слегка отличаться по версии Tauri):

- **macOS:** `src-tauri/target/release/bundle/macos/*.app` — пользователь перетаскивает в «Программы»
- **Windows:** `src-tauri/target/release/bundle/nsis/*.exe` (установщик) или исполняемый файл в `bundle/`

Это воспринимается как «настоящая программа»: своё окно, «Сохранить как», рецепты в AppData.

---

## Что выбрать

- **Коллеге на Windows без прав администратора** → portable HTML или `.bat`.
- **Постоянная работа на Mac** → собрать `.app` через Tauri.
- **Windows** → portable (`npm run build:portable`), zip папки `release/`.

---

## Частые вопросы

**Почему не один .exe без Rust?**  
React + Excel-библиотеки (~2 МБ JS) в чистый нативный бинарник без WebView всё равно упаковываются через Tauri/Electron — это тот же движок, что и HTML, но в оболочке ОС.

**Safari и file://**  
Для portable лучше Chrome или Edge; при проблемах с localStorage открывайте через скрипт запуска (он вызывает `open` / `start` с системным браузером по умолчанию).

**Обновление версии**  
Portable: заменить один HTML. Desktop: переустановить .app / exe.
